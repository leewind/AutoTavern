# LeeAgent 演进路线:前四率 64% → 70%+

状态基准(2026-11-02,policy v16,commit `8e8dc89`):

| 指标 | 数值 |
| :--- | :--- |
| 终评前四率 | 64%(seeds 1200–1299,bot 参照 59%) |
| 真实水平估计 | ~61%(dev 58 / holdout 64) |
| 平均名次 | 3.59,第 8 名 4/100,冠军 24/100 |
| 单局成本 | ~1 秒(纯代码臂,96 核可并行) |

目标:前四率 ≥70%(需 +9pp)。以下按性价比排序,每项注明依据、预期增益、把握度与成本。
评测纪律:dev=300–399,holdout=400–499,终评用全新种子段;特性采纳必须双集一致
(hero-text 事故教训:单集采纳曾造成 holdout −17pp 的隐性损失)。

---

## 第一梯队:环境数据训练(便宜、把握大)

### ① 经验英雄强度表 ★★★★☆
- **做什么**:96 核并行,116 个英雄 × 20 局 bot 对局(约 40 分钟)→ 经验胜率表 →
  英雄二选一选强者。
- **依据**:英雄选择位置价值 ~17pp(hero-text 事故的反面证明);文本启发方向选反,
  应改用环境实测。
- **预期**:+3~4pp。**成本**:半天(含验证)。

### ② 经验饰品强度表 ★★★☆☆
- **做什么**:236 个饰品 × 各 20 局 → 全局强度先验,替换现有文本启发
  (文本版已值 +19pp)。进阶:按当前部族/等级分桶。
- **预期**:+1~3pp。**成本**:1 天。

---

## 第二梯队:补齐两个结构性短板

### ③ 部族成型模型(5–7 名的病根)★★★☆☆
- **做什么**:现在买牌是逐卡评分(身材+等级+关键词+4 分部族倾向),缺"早期定方向
  → 全情投入"的成型逻辑:
  1. 方向决策(每局一次,第 4–6 回合):根据英雄 + 已有对子选定部族 —— 正是
     Nimble choice 的适用场景,记忆层的真正用武之地;
  2. 成型度追踪(部族计数 + 核心件持有);
  3. 外族清理(成型后卖非部族件)。
- **依据**:死亡画像显示 5–7 名 = 中期成型不足被反超;真人玩家的核心优势即在此。
- **预期**:+3~5pp。**成本**:2–3 天。

### ④ 无对手依赖的通用站位 ★★★☆☆
- **做什么**:站位前瞻死于过期对手面板,但半数站位决策不需要对手信息:
  亡语召唤靠右、风怒居左、嘲讽贴核心、buff 载体受保护。普适规则,不查面板。
- **依据**:带 preview 的站位(过期信息)双集负收益;这些规则零信息依赖,无此风险。
- **预期**:+1~3pp。**成本**:半天。

### ⑤ 合成面板侦察 ★★☆☆☆
- **做什么**:从上万局 bot 对局统计"第 T 回合平均面板分布",引擎生成合成对手,
  侦察信号对合成面板预演 —— 信息永远新鲜。TavernAgent 的 256 次前瞻即此思路。
- **依据**:现行侦察信号(+7pp)受限于过期面板;这是其自然升级。
- **预期**:+2~4pp。**成本**:2 天。

## 第三梯队:架构承诺的兑现(方差大)

### ⑥ 记忆层表达力解锁
- **做什么**:本轮证明 bias 幅值在带状优先级结构里是二阶杠杆(全扫描无效),
  因为动词词表只有 8 个且都是分数微调。扩展动词词表(部族承诺、卖点取舍、
  技能时机、站位姿态)后,记忆才能携带新规则;再程序化批量生成 50+ 条跑世代进化。
- **第一批实证(2026-11-02,已结案)**:冷路径蒸馏的 9 条候选全数被门否决——
  批量门 −0.014;逐条门筛出的 M29/M30 是多重比较假阳性(9 条 × ±0.04 噪声,
  单集期望 ~2 条假胜出),组合门 −0.046/−0.094,M29 单独复现 −0.009/+0.029 失败。
  教训:①门的协议必须含独立复现集;②从中等水平 agent 的对局日志蒸馏不出
  增量信号,蒸馏源要先变强(或改为程序化模板生成)。
- **预期**:+1~3pp,方差大。**成本**:2–3 天。

### ⑦ 轨迹级学习(通往 70%+ 的真正桥梁)
- **做什么**:自博弈 1 万局 → 每回合 facts/决策/最终名次 → 拟合名次预测器
  (GBDT 即可)→ 用预测器门控关键决策(升级时机、全押时机)。是从手写启发到
  拟合策略的过渡,不需要 PPO 基础设施。
- **预期**:+3~6pp。**成本**:3–5 天。

## 叠加估算与执行顺序

```
现在 ~61%(真实)
  ① 英雄表     +3   ← 先做:40 分钟计算,把握最大
  ③ 成型模型   +3   ← 直击 5–7 名病灶
  ⑤ 合成侦察   +2
  ② 饰品表     +2
  ④ 通用站位   +1
  ⑥ 记忆进化   +1
  ≈ 70% ± 3
```

诚实的天花板:启发式 + 数据表路线约 **68~72%**;75%+ 必须走 ⑦ 轨迹学习或论文的
PPO 路线(TavernAgent 的 bench 91% 即那条路的终点)。
