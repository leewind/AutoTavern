## 第二梯队:补齐两个结构性短板

### ③ 部族成型模型(5–7 名的病根)★★★☆☆
- **做什么**:现在买牌是逐卡评分(身材+等级+关键词+4 分部族倾向),缺"早期定方向
  → 全情投入"的成型逻辑:
  1. 方向决策(每局一次,第 4–6 回合):根据英雄 + 已有对子选定部族 —— 正是
     Nimble choice 的适用场景,记忆层的真正用武之地;
  2. 成型度追踪(部族计数 + 核心件持有);
  3. 外族清理(成型后卖非部族件)。
- **依据**:死亡画像显示 5–7 名 = 中期成型不足被反超;真人玩家的核心优势即在此。
- **预期**:+3~5pp。**成本**:2–3 天。

### ④ 无对手依赖的通用站位 ★★★☆☆
- **做什么**:站位前瞻死于过期对手面板,但半数站位决策不需要对手信息:
  亡语召唤靠右、风怒居左、嘲讽贴核心、buff 载体受保护。普适规则,不查面板。
- **依据**:带 preview 的站位(过期信息)双集负收益;这些规则零信息依赖,无此风险。
- **预期**:+1~3pp。**成本**:半天。

### ⑤ 合成面板侦察 ★★☆☆☆
- **做什么**:从上万局 bot 对局统计"第 T 回合平均面板分布",引擎生成合成对手,
  侦察信号对合成面板预演 —— 信息永远新鲜。TavernAgent 的 256 次前瞻即此思路。
- **依据**:现行侦察信号(+7pp)受限于过期面板;这是其自然升级。
- **预期**:+2~4pp。**成本**:2 天。

## 第三梯队:架构承诺的兑现(方差大)

### ⑥ 记忆层表达力解锁
- **做什么**:本轮证明 bias 幅值在带状优先级结构里是二阶杠杆(全扫描无效),
  因为动词词表只有 8 个且都是分数微调。扩展动词词表(部族承诺、卖点取舍、
  技能时机、站位姿态)后,记忆才能携带新规则;再程序化批量生成 50+ 条跑世代进化。
- **第一批实证(2026-11-02,已结案)**:冷路径蒸馏的 9 条候选全数被门否决——
  批量门 −0.014;逐条门筛出的 M29/M30 是多重比较假阳性(9 条 × ±0.04 噪声,
  单集期望 ~2 条假胜出),组合门 −0.046/−0.094,M29 单独复现 −0.009/+0.029 失败。
  教训:①门的协议必须含独立复现集;②从中等水平 agent 的对局日志蒸馏不出
  增量信号,蒸馏源要先变强(或改为程序化模板生成)。
- **预期**:+1~3pp,方差大。**成本**:2–3 天。

### ⑦ 轨迹级学习(通往 70%+ 的真正桥梁)
- **做什么**:自博弈 1 万局 → 每回合 facts/决策/最终名次 → 拟合名次预测器
  (GBDT 即可)→ 用预测器门控关键决策(升级时机、全押时机)。是从手写启发到
  拟合策略的过渡,不需要 PPO 基础设施。
- **预期**:+3~6pp。**成本**:3–5 天。

## 阈值调参的收敛决议(2026-11-02)

对英雄表与成型模型的调参评估结论:

- **英雄表**:真正杠杆是样本量,不是阈值。K=16 的估计噪声
  (SE≈±0.35 名次)大于中段英雄间的真实差距(<0.5),live 200 局配对平局
  (29/31)的根因在此。**已执行:K→64**(7360 局,~3 分钟),200 局配对
  +0.16 名次(23好/17差),采纳。**收缩被证伪为数学惰性**:对两个同表英雄
  做相同的仿射收缩 `α·m+(1−α)·g` 不改变排序(对 m 单调),实测 0/200 局
  差异;它只在"表内 vs 表外启发混比"时有效,已移除。
- **成型模型**:8 个实阈值(时机 turn≥4 / 门槛 ≥2 / 亲和 3.0 / 密度 3.0 /
  协同 1.5 / 成型买分 +3+4x / 外族税 −4 / 卖牌保护 +6)可做坐标上升,但
  历史命中率低(活的全是结构性改动,死的全是微调),期望 +1~3pp、
  可能全被 holdout 毙——排在英雄表之后,协议:dev 调 → holdout 复核 →
  全新集终验,每配置 200 局起评(单集噪声 ±4~5pp)。
- **不碰**:成型承诺门槛降到 1(弱化方向依据,机制倒退)。

## 专项:追平 TavernAgent 的策略类差距(0.36 → 0.75)

机理:N1/N2 用**被测系统自己的策略续打**来区分方案。我们的续打把好坏方案
打成相近名次——差距在经营水平,不在选项判断。

**执行实绩(2026-11-02)**:play 0.86 → **0.87**(selection 0.61→0.68,
strategy 未突破)。各步结果:

| 步骤 | 结果 |
| :--- | :--- |
| 0a rollout 12→24 | 零变化——瓶颈是续打判别力,不是采样噪声(诊断价值高) |
| 0b 经验英雄表(115 英雄×16 局) | selection +0.01;live 200 局配对平局(29/31)——表无害且机制更优,保留;强度差实测 2.25→6.56 名次 |
| 1 成型模型 v1(方向决策+成型买分+外族税+保护卖) | selection +0.03,live holdout +4pp(dev 平)——采纳 |
| 2 价值模型 v1(78 万行,LightGBM,RMSE 0.506) | **纯模型评分更差**(strat 0.21);混合制(初筛 top-2 + rollout 终审)play 0.87——采纳 |

**Strategy 0.30 的诚实结论**:N 类判别力被续打策略强度锁死,价值模型 v1 的
粗特征(28 维)分不出细差距。突破路径:(a) 更强特征(对手面板/手牌/商店
内容);(b) 成型模型 v2(成型度、核心件计数入特征);(c) 最终仍是 ⑦ 的
PPO/搜索路线。与 TavernAgent 的 0.04 差距 = 经营水平的最后一段。

### ③ 成型模型五组件(`leeagent/comp.py`)

1. **方向决策**(每局一次,turn 4–6):部族方向得分 = 成型收益表(卡池引擎密度×
   等级可达性)+ 面板亲和度 + 英雄协同;Nimble choice 的天然用武之地
2. **成型感知买分**:承诺部族内带引擎文案的卡 +8~12;外族高身材 −4(落后时例外)
3. **外族清理**:turn≥9 且成型件≥4 时,卖牌准则加"非成型件"轴
4. **成型内三连**:三连寻求(+25)加部族过滤
5. **成型度追踪**:核心件计数入 facts,联动升级门与侦察

### ⑦ 价值模型四步

1. v16 自博弈 1 万局(96 核约 30 分钟),每决策点记 `(facts, 动作, 最终名次)`
   ≈ 120 万样本

3. **基准接入**:N/D 类从 12 局 rollout 换成价值评分 + top-2 验证 rollout
4. **对局接入**:E[名次|升级] vs E[名次|买] 直接比较,退役手工门;
   终极形态 = 245 动作全合法集上的一步搜索(毫秒级)
