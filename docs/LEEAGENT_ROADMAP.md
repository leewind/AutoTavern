## 阈值调参的收敛决议(2026-11-02)

对英雄表与成型模型的调参评估结论:

- **英雄表**:真正杠杆是样本量,不是阈值。K=16 的估计噪声
  (SE≈±0.35 名次)大于中段英雄间的真实差距(<0.5),live 200 局配对平局
  (29/31)的根因在此。**已执行:K→64**(7360 局,~3 分钟),200 局配对
  +0.16 名次(23好/17差),采纳。**收缩被证伪为数学惰性**:对两个同表英雄
  做相同的仿射收缩 `α·m+(1−α)·g` 不改变排序(对 m 单调),实测 0/200 局
  差异;它只在"表内 vs 表外启发混比"时有效,已移除。
- **成型模型**:8 个实阈值(时机 turn≥4 / 门槛 ≥2 / 亲和 3.0 / 密度 3.0 /
  协同 1.5 / 成型买分 +3+4x / 外族税 −4 / 卖牌保护 +6)可做坐标上升,但
  历史命中率低(活的全是结构性改动,死的全是微调),期望 +1~3pp、
  可能全被 holdout 毙——排在英雄表之后,协议:dev 调 → holdout 复核 →
  全新集终验,每配置 200 局起评(单集噪声 ±4~5pp)。
- **不碰**:成型承诺门槛降到 1(弱化方向依据,机制倒退)。

## 专项:追平 TavernAgent 的策略类差距(0.36 → 0.75)

机理:N1/N2 用**被测系统自己的策略续打**来区分方案。我们的续打把好坏方案
打成相近名次——差距在经营水平,不在选项判断。

**执行实绩(2026-11-02)**:play 0.86 → **0.87**(selection 0.61→0.68,
strategy 未突破)。各步结果:

| 步骤 | 结果 |
| :--- | :--- |
| 0a rollout 12→24 | 零变化——瓶颈是续打判别力,不是采样噪声(诊断价值高) |
| 0b 经验英雄表(115 英雄×16 局) | selection +0.01;live 200 局配对平局(29/31)——表无害且机制更优,保留;强度差实测 2.25→6.56 名次 |
| 1 成型模型 v1(方向决策+成型买分+外族税+保护卖) | selection +0.03,live holdout +4pp(dev 平)——采纳 |
| 2 价值模型 v1(78 万行,LightGBM,RMSE 0.506) | **纯模型评分更差**(strat 0.21);混合制(初筛 top-2 + rollout 终审)play 0.87——采纳 |

**Strategy 0.30 的诚实结论**:N 类判别力被续打策略强度锁死,价值模型 v1 的
粗特征(28 维)分不出细差距。突破路径:(a) 更强特征(对手面板/手牌/商店
内容);(b) 成型模型 v2(成型度、核心件计数入特征);(c) 最终仍是 ⑦ 的
PPO/搜索路线。与 TavernAgent 的 0.04 差距 = 经营水平的最后一段。

### ③ 成型模型五组件(`leeagent/comp.py`)

1. **方向决策**(每局一次,turn 4–6):部族方向得分 = 成型收益表(卡池引擎密度×
